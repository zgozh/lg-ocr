# 预训练模型使用说明

## 📁 目录结构

```
pretrained_models/
├── det/
│   └── PP-OCRv5_server_det_pretrained.pdparams    (101 MB)
├── rec/
│   └── PP-OCRv5_server_rec_pretrained.pdparams    (205 MB)
└── table/
    └── SLANeXt_wired_pretrained.pdparams          (184 MB)
```

## 🎯 使用方法

### 在图形界面中使用

1. 启动图形界面：`python gui.py`
2. 切换到"模型训练"标签页
3. 选择模型类型
4. 配置数据集路径
5. 在"预训练模型"中点击"浏览..."
6. 选择对应的预训练模型文件：

| 模型类型 | 预训练模型路径 |
|---------|---------------|
| PP-OCRv5_server_det (检测) | `pretrained_models/det/PP-OCRv5_server_det_pretrained.pdparams` |
| PP-OCRv5_server_rec (识别) | `pretrained_models/rec/PP-OCRv5_server_rec_pretrained.pdparams` |
| SLANeXt_wired (表格) | `pretrained_models/table/SLANeXt_wired_pretrained.pdparams` |

## ✨ 使用预训练模型的好处

### 1. 加快收敛速度
- 从零开始训练可能需要数百个 epoch
- 使用预训练模型可以减少 50-70% 的训练时间

### 2. 提高最终精度
- 预训练模型已经学习了通用的文字特征
- 在你的数据集上微调可以获得更好的效果

### 3. 减少数据需求
- 从零训练可能需要数万张图片
- 使用预训练模型，几千张图片就能获得不错的效果

## 🔧 训练参数建议

### 使用预训练模型时

**学习率**：
- 建议使用较小的学习率（0.0001 - 0.001）
- 避免破坏预训练权重

**Epoch 数量**：
- 检测模型：100-200 epoch
- 识别模型：100-300 epoch
- 表格模型：100-200 epoch

**Batch Size**：
- 根据显存调整
- 建议与预训练时保持一致

## ⚠️ 注意事项

### 1. 模型匹配

确保选择的预训练模型与训练的模型类型一致：
- ✅ 训练识别模型 → 使用识别预训练模型
- ❌ 训练识别模型 → 使用检测预训练模型（会报错）

### 2. 路径正确

在界面中选择预训练模型时：
- 使用"浏览..."按钮选择文件
- 或直接输入完整路径
- 确保路径中没有中文或特殊字符

### 3. 文件完整性

如果训练时提示模型加载失败：
- 检查文件大小是否正确
- 重新下载预训练模型

### 4. 可选使用

预训练模型是**可选的**：
- 如果不使用，留空即可
- 系统会从零开始训练
- 但训练时间会更长

## 📞 常见问题

### Q1: 预训练模型加载失败？

**A:** 检查：
1. 文件路径是否正确
2. 文件是否完整（大小是否正确）
3. 模型类型是否匹配

### Q2: 使用预训练模型后效果反而变差？

**A:** 可能原因：
1. 学习率过大，破坏了预训练权重 → 降低学习率
2. 数据集与预训练数据差异太大 → 尝试从零训练
3. 训练时间不够 → 增加 epoch 数量

### Q3: 可以混用不同版本的预训练模型吗？

**A:** 不建议。应该使用与当前代码版本匹配的预训练模型。

### Q4: 预训练模型占用空间太大？

**A:** 
- 检测模型：101 MB
- 识别模型：205 MB
- 表格模型：184 MB
- 总计：约 490 MB

如果空间不足，可以只保留需要训练的模型类型。
