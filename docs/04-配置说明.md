# DocExtractor 文档信息提取系统 - 配置说明

## 📋 配置文件概述

系统使用两类配置文件：
- `config.json` - 系统配置（Ollama、模型、设备）
- `templates/*.json` - 文档模板（字段、规则、输出）

---

## ⚙️ config.json 配置说明

### 完整配置示例

```json
{
  "ollama": {
    "host": "http://localhost:11434",
    "model": "deepseek-r1:32b",
    "max_retries": 3,
    "retry_delay_seconds": 1.0
  },
  "device": "gpu:0",
  "models": {
    "layout_detection": {
      "name": "PP-DocLayout-L",
      "path": "C:/ocr-llm/models/PP-DocLayout-L"
    },
    "text_recognition": {
      "name": "PP-OCRv5_server_rec",
      "path": "C:/ocr-llm/models/PP-OCRv5_server_rec"
    },
    "text_detection": {
      "name": "PP-OCRv5_server_det",
      "path": "C:/ocr-llm/models/PP-OCRv5_server_det"
    }
    // ... 其他模型配置
  },
  "pipeline": {
    "use_layout_detection": true,
    "use_doc_orientation_classify": false,
    "use_doc_unwarping": false
  }
}
```

---

### 1. ollama 配置

#### host - Ollama 服务地址
```json
"host": "http://localhost:11434"
```

**说明：** LLM 服务的访问地址

**常用配置：**
- 本地服务：`http://localhost:11434`
- 远程服务：`http://192.168.1.100:11434`
- 自定义端口：`http://localhost:8080`

#### model - LLM 模型名称
```json
"model": "deepseek-r1:32b"
```

**说明：** 使用的大语言模型

**推荐模型：**
| 模型 | 大小 | 速度 | 准确率 | 适用场景 |
|------|------|------|--------|---------|
| deepseek-r1:32b | 32B | 中 | 高 | 生产环境（推荐） |
| qwen2.5:32b | 32B | 中 | 高 | 生产环境 |
| qwen2.5:14b | 14B | 快 | 中高 | 快速处理 |
| qwen2.5:7b | 7B | 很快 | 中 | 测试/开发 |

#### max_retries - 失败重试次数
```json
"max_retries": 3
```

**说明：** LLM 提取失败后的重试次数

**建议值：**
- 生产环境：3-5 次
- 测试环境：1-2 次

#### retry_delay_seconds - 重试间隔
```json
"retry_delay_seconds": 1.0
```

**说明：** 两次重试之间的等待时间（秒）

**建议值：**
- 本地服务：0.5-1.0 秒
- 远程服务：1.0-2.0 秒

---

### 2. device 配置

```json
"device": "gpu:0"
```

**说明：** OCR 模型运行的设备

**可选值：**
- `gpu:0` - 使用第一块 GPU（推荐）
- `gpu:1` - 使用第二块 GPU
- `cpu` - 使用 CPU（速度较慢）

**性能对比：**
| 设备 | 速度 | 适用场景 |
|------|------|---------|
| GPU | 3-5 秒/张 | 生产环境（推荐） |
| CPU | 30-60 秒/张 | 无 GPU 环境 |

---

### 3. models 配置

定义 OCR 模型的名称和路径。

#### 配置格式
```json
"模型类型": {
  "name": "模型名称",
  "path": "模型目录的绝对路径"
}
```

#### 必需的 8 个模型

**1. layout_detection - 版面分析**
```json
"layout_detection": {
  "name": "PP-DocLayout-L",
  "path": "C:/ocr-llm/models/PP-DocLayout-L"
}
```

**2. table_classification - 表格分类**
```json
"table_classification": {
  "name": "PP-LCNet_x1_0_table_cls",
  "path": "C:/ocr-llm/models/PP-LCNet_x1_0_table_cls"
}
```

**3. wired_table_structure_recognition - 有线表格识别**
```json
"wired_table_structure_recognition": {
  "name": "SLANeXt_wired",
  "path": "C:/ocr-llm/models/SLANeXt_wired"
}
```

**4. wireless_table_structure_recognition - 无线表格识别**
```json
"wireless_table_structure_recognition": {
  "name": "SLANeXt_wireless",
  "path": "C:/ocr-llm/models/SLANeXt_wireless"
}
```

**5. wired_table_cells_detection - 有线表格单元格检测**
```json
"wired_table_cells_detection": {
  "name": "RT-DETR-L_wired_table_cell_det",
  "path": "C:/ocr-llm/models/RT-DETR-L_wired_table_cell_det"
}
```

**6. wireless_table_cells_detection - 无线表格单元格检测**
```json
"wireless_table_cells_detection": {
  "name": "RT-DETR-L_wireless_table_cell_det",
  "path": "C:/ocr-llm/models/RT-DETR-L_wireless_table_cell_det"
}
```

**7. text_recognition - 文字识别**
```json
"text_recognition": {
  "name": "PP-OCRv5_server_rec",
  "path": "C:/ocr-llm/models/PP-OCRv5_server_rec"
}
```

**8. text_detection - 文字检测**
```json
"text_detection": {
  "name": "PP-OCRv5_server_det",
  "path": "C:/ocr-llm/models/PP-OCRv5_server_det"
}
```

#### 路径配置注意事项

**Windows 路径：**
```json
"path": "C:/ocr-llm/models/PP-OCRv5_server_rec"
```
或
```json
"path": "C:\\ocr-llm\\models\\PP-OCRv5_server_rec"
```

**Linux 路径：**
```json
"path": "/opt/ocr-llm/models/PP-OCRv5_server_rec"
```

**重要：**
- 必须使用绝对路径
- 路径指向模型目录，不是具体文件
- 确保目录存在且包含模型文件

---

### 4. pipeline 配置

控制 OCR 流程中的功能开关。

#### use_layout_detection - 版面分析
```json
"use_layout_detection": true
```

**说明：** 是否启用版面分析

**建议：**
- 包含表格：必须启用（true）
- 纯文本：可禁用（false）

#### use_doc_orientation_classify - 文档方向分类
```json
"use_doc_orientation_classify": false
```

**说明：** 是否检测和矫正文档方向

**建议：**
- 文档方向正确：禁用（false）
- 可能倾斜或旋转：启用（true）

#### use_doc_unwarping - 文档矫正
```json
"use_doc_unwarping": false
```

**说明：** 是否进行文档变形矫正

**建议：**
- 扫描件质量好：禁用（false）
- 拍照或变形严重：启用（true）

## 📝 模板配置说明

模板文件位于 `templates/` 目录，定义了文档的字段和提取规则。

### 完整模板示例

```json
{
  "name": "hukou_register",
  "display_name": "常住人口登记表",
  "fields": [
    {
      "name": "姓名",
      "default": "X",
      "description": "人员姓名"
    },
    {
      "name": "性别",
      "default": "X",
      "description": "性别"
    }
  ],
  "prompt": {
    "document_type": "常住人口登记表",
    "rules": [
      "严格按照OCR结果从左到右、从上到下的顺序理解内容。",
      "仅提取OCR文本中明确存在的信息，不得自行添加、修改或猜测。"
    ]
  },
  "fallback_record": {
    "姓名": "X",
    "性别": "X"
  },
  "output": {
    "sheet_name": "Sheet",
    "text_columns": ["出生日期"],
    "first_row_overrides": {
      "与户主关系": "户主"
    },
    "columns": [
      {
        "header": "姓名",
        "source": "field",
        "field": "姓名"
      },
      {
        "header": "案卷号",
        "source": "image_parent_name"
      },
      {
        "header": "原始图片名称",
        "source": "image_name"
      }
    ]
  }
}
```

---

### 1. 基本信息

```json
"name": "hukou_register",
"display_name": "常住人口登记表"
```

- `name` - 模板唯一标识符（英文）
- `display_name` - 显示名称（中文）

---

### 2. fields - 字段定义

定义要从文档中提取的字段。

```json
"fields": [
  {
    "name": "姓名",              // 字段名称
    "default": "X",             // 默认值
    "description": "人员姓名"    // 字段说明
  }
]
```

**default 值说明：**
- `"X"` - 必填字段，缺失时标记为 X
- `""` - 可选字段，缺失时留空

---

### 3. prompt - 提取规则

指导 LLM 如何提取信息。

```json
"prompt": {
  "document_type": "常住人口登记表",
  "rules": [
    "严格按照OCR结果从左到右、从上到下的顺序理解内容。",
    "仅提取OCR文本中明确存在的信息，不得自行添加、修改或猜测。"
  ]
}
```

**编写建议：**
- 规则要具体、可执行
- 优先级高的规则放在前面
- 包含异常情况的处理说明

---

### 4. fallback_record - 兜底数据

LLM 提取失败时使用的默认记录。

```json
"fallback_record": {
  "姓名": "X",
  "性别": "X"
}
```

**作用：** 确保每张图片都有记录，标记失败的图片。

---

### 5. output - 输出配置

#### sheet_name - 工作表名称
```json
"sheet_name": "Sheet"
```

#### text_columns - 文本格式列
```json
"text_columns": ["出生日期", "证件号码"]
```

**作用：** 防止 Excel 自动转换数据格式

**应该包含：**
- 日期字段
- 身份证号
- 编号（有前导零）

#### first_row_overrides - 首行覆盖
```json
"first_row_overrides": {
  "与户主关系": "户主"
}
```

**作用：** 强制修改第一行特定字段的值

#### columns - 列定义

定义 Excel 输出的每一列。

**4 种数据来源：**

**1. field - 从提取字段获取**
```json
{
  "header": "姓名",
  "source": "field",
  "field": "姓名"
}
```

**2. constant - 固定值**
```json
{
  "header": "档号",
  "source": "constant",
  "value": ""
}
```

**3. image_name - 图片文件名**
```json
{
  "header": "原始图片名称",
  "source": "image_name"
}
```

**4. image_parent_name - 图片所在目录名**
```json
{
  "header": "案卷号",
  "source": "image_parent_name"
}
```

## 🔧 配置修改方法

### 方法 1：通过菜单修改

1. 启动程序：`python menu.py`
2. 选择 `[2] 设置`
3. 选择要修改的配置项

### 方法 2：直接编辑文件

1. 使用文本编辑器打开配置文件
2. 修改相应配置项
3. 保存文件
4. 重启程序

**验证 JSON 格式：**
```bash
python -m json.tool config.json
```
