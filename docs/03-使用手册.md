**使用场景：**
- 使用不同的 Ollama 服务地址
- 使用不同的 LLM 模型
- 切换 GPU/CPU 运行模式

**操作步骤：**
```

[验证中...]

已更新！
```

#### [2] 修改模板文件路径

选择或指定文档模板。

**使用场景：**
- 处理不同类型的文档
- 使用自定义模板
- 切换内置模板

**操作步骤：**
```
内置模板:
  [1] hukou_register.json

请输入路径或编号 (输入 'c' 取消): 1

[验证中...]
✓ 模板文件有效 (15个字段)

```

#### [3] 切换隔页推理

开启或关闭隔页推理模式。

**功能说明：**
- 启用后，只处理奇数索引或偶数索引的图片
- 适用于双面扫描文档的分批处理

**使用场景：**
```
目录中的文件: 
  0001.jpg, 0002.jpg, 0003.jpg, 0004.jpg

启用隔页推理后只处理: 
  0001.jpg, 0003.jpg
```

**操作步骤：**
```

说明: 启用后只处理奇数或偶数页图片

确认切换为 [否]? (y/n): y

✓ 已切换为: 否
```

## 💡 使用技巧

### 1. 图片质量要求

**推荐：**
- 分辨率：300 DPI 以上
- 格式：JPG、PNG
- 清晰度：文字清晰可辨
- 方向：正向摆放

**避免：**
- 模糊、过暗、过亮
- 严重倾斜或变形
- 分辨率过低（< 150 DPI）

### 2. 批量处理建议

**小批量处理（推荐）：**
- 每批 50-100 张图片
- 便于检查结果
- 出错影响范围小

**大批量处理：**
- 确保系统稳定
- 预留足够磁盘空间
- 建议分批次处理

### 3. 结果检查

**重点检查：**
- 标记为 "X" 的记录
- 日期格式是否正确
- 身份证号是否完整
- 姓名是否准确

**快速筛选：**
在 Excel 中使用筛选功能，筛选包含 "X" 的行。

### 4. 错误处理

**处理失败的图片：**
1. 查看 `result/{图片名}.json` 中的 OCR 结果
2. 检查图片质量
3. 尝试重新扫描或拍照
4. 手工补录数据

## 📈 性能优化

### 提升处理速度

1. **使用 GPU**
   - 修改 `config.json` 中的 `device` 为 `gpu:0`
   - 速度提升 10-20 倍

2. **使用更小的模型**
   - 修改 `model` 为 `qwen2.5:7b`
   - 速度提升 2-3 倍，精度略降

3. **关闭不必要的功能**
   - 无表格文档：关闭版面分析

### 提升识别准确率

1. **提高图片质量**
   - 使用高分辨率扫描（300 DPI+）
   - 确保光线充足、文字清晰

2. **使用更强大的模型**
   - 使用 `deepseek-r1:32b` 或 `qwen2.5:32b`

## 🔍 常见问题

### Q1: 如何处理双面扫描的文档？

**A:** 使用隔页推理功能
1. 第一次处理：启用隔页推理，处理正面
2. 第二次处理：再次启用隔页推理，处理反面

### Q2: Excel 中日期格式不对怎么办？

**A:** 日期列已设置为文本格式，如果仍有问题：
1. 选中日期列
2. 右键 → 设置单元格格式
3. 选择"文本"

### Q3: 处理速度太慢怎么办？

**A:** 参考"性能优化"章节，主要方法：
1. 使用 GPU
2. 使用更小的模型
3. 关闭不必要的功能

### Q4: 识别结果不准确怎么办？

**A:** 
1. 检查图片质量
2. 使用更强大的模型
3. 调整模板的提取规则
