## 安装问题

### Q1: pip 安装速度很慢怎么办？

**A:** 使用国内镜像源

```bash
# 临时使用
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple <包名>

# 永久配置
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
```

**常用镜像源：**
- 清华：https://pypi.tuna.tsinghua.edu.cn/simple
- 阿里：https://mirrors.aliyun.com/pypi/simple/
- 腾讯：https://mirrors.cloud.tencent.com/pypi/simple

---

### Q2: 安装 PaddlePaddle 时报错 CUDA 版本不匹配？

**A:** 检查 CUDA 版本并安装对应版本

```bash
# 查看 CUDA 版本
nvidia-smi

# 根据版本选择：
# CUDA 12.9
pip install paddlepaddle-gpu==3.1.1 -i https://www.paddlepaddle.org.cn/packages/stable/cu129/

# CUDA 11.8
pip install paddlepaddle-gpu==3.1.1 -i https://www.paddlepaddle.org.cn/packages/stable/cu118/

# 没有 GPU 使用 CPU 版本
pip install paddlepaddle==3.1.1
```

---

### Q3: 提示缺少某个 Python 包怎么办？

**A:** 安装缺失的包

```bash
pip install <包名>

# 例如：
pip install ollama
pip install tqdm
pip install openpyxl
```

## 配置问题

### Q4: 如何修改 Ollama 服务地址？

**A:** 修改 `config.json`

```json
{
  "ollama": {
    "host": "http://192.168.1.100:11434",  // 修改为实际地址
    "model": "deepseek-r1:32b"
  }
}
```

---

### Q5: 提示"模型文件找不到"怎么办？

**A:** 检查并修正模型路径

1. 确认模型文件确实存在
2. 使用绝对路径
3. 检查路径格式（Windows 使用 `/` 或 `\\`）

```json
// 正确示例
"path": "C:/ocr-llm/models/PP-OCRv5_server_rec"

// 或
"path": "C:\\ocr-llm\\models\\PP-OCRv5_server_rec"
```

---

### Q6: 如何切换使用 CPU 而不是 GPU？

**A:** 修改 `config.json` 中的 device

```json
{
  "device": "cpu"  // 改为 cpu
}
```

## 运行问题

### Q7: 提示"Ollama 连接失败"怎么办？

**A:** 按以下步骤排查

**步骤 1：检查 Ollama 服务是否启动**
```bash
# Windows
# 查看任务管理器中是否有 ollama 进程

# Linux
ps aux | grep ollama
```

**步骤 2：手动启动 Ollama**
```bash
ollama serve
```

**步骤 3：测试连接**
```bash
curl http://localhost:11434/api/tags
```

**步骤 4：检查模型是否存在**
```bash
ollama list
```

**步骤 5：拉取模型**
```bash
ollama pull deepseek-r1:32b
```

---

### Q8: 程序启动后卡住不动？

**A:** 可能原因和解决方案

**原因 1：首次加载模型较慢**
- 等待 2-5 分钟
- 模型加载完成后会显示提示

**原因 2：Ollama 服务无响应**
- 重启 Ollama 服务
- 检查网络连接

**原因 3：GPU 内存不足**
- 关闭其他占用 GPU 的程序
- 或改用 CPU 模式

---

### Q9: 提示"CUDA out of memory"怎么办？

**A:** GPU 显存不足

**解决方案：**
1. 关闭其他占用 GPU 的程序
2. 使用更小的 LLM 模型
3. 改用 CPU 模式

```json
{
  "device": "cpu",
  "ollama": {
    "model": "qwen2.5:7b"  // 使用更小的模型
  }
}
```

## 识别问题

### Q10: 识别结果不准确怎么办？

**A:** 多方面优化

**1. 提高图片质量**
- 使用 300 DPI 以上扫描
- 确保文字清晰
- 避免模糊、过暗、过亮

**2. 使用更强大的模型**
```json
{
  "ollama": {
    "model": "deepseek-r1:32b"  // 使用 32B 模型
  }
}
```

**4. 调整模板规则**
- 修改 `templates/*.json` 中的 `prompt.rules`
- 添加更具体的提取规则

---

### Q11: 日期格式识别错误？

**A:** 检查模板配置

确保日期字段在 `text_columns` 中：

```json
{
  "output": {
    "text_columns": ["出生日期", "登记日期"]
  }
}
```

---

### Q12: 身份证号变成科学计数法？

**A:** 添加到 text_columns

```json
{
  "output": {
    "text_columns": ["证件号码", "身份证号"]
  }
}
```

---

### Q13: 表格识别失败？

**A:** 检查配置

确保启用版面分析：

```json
{
  "pipeline": {
    "use_layout_detection": true  // 必须为 true
  }
}
```

## 性能问题

### Q14: 处理速度太慢怎么办？

**A:** 多种优化方法

**方法 1：使用 GPU（最有效）**
```json
{
  "device": "gpu:0"
}
```
速度提升 10-20 倍

**方法 2：使用更小的模型**
```json
{
  "ollama": {
    "model": "qwen2.5:7b"  // 从 32b 改为 7b
  }
}
```
速度提升 2-3 倍

**方法 3：关闭不必要的功能**
```json
{
  "pipeline": {
    "use_doc_orientation_classify": false,
    "use_doc_unwarping": false
  }
}
```

**方法 4：减少重试次数**
```json
{
  "ollama": {
    "max_retries": 1  // 从 3 改为 1
  }
}
```

---

### Q15: GPU 使用率很低？

**A:** 可能原因

**原因 1：瓶颈在 LLM**
- LLM 推理在 CPU 上进行
- 这是正常现象

**原因 2：批量大小太小**
- 单张处理无法充分利用 GPU
- 这是设计限制

## 输出问题

### Q16: Excel 文件打不开？

**A:** 可能原因和解决方案

**原因 1：文件被占用**
- 关闭已打开的 Excel 文件
- 重新运行程序

**原因 2：文件损坏**
- 删除 output.xlsx
- 重新处理

---

### Q17: Excel 中有很多 "X" 怎么办？

**A:** "X" 表示字段提取失败

**处理方法：**
1. 筛选包含 "X" 的行
2. 查看对应的 JSON 结果文件
3. 检查 OCR 识别是否准确
4. 手工补录或重新处理

---

### Q18: 如何批量筛选失败的记录？

**A:** 使用 Excel 筛选功能

1. 打开 output.xlsx
2. 选中数据区域
3. 数据 → 筛选
4. 点击列标题的下拉箭头
5. 筛选包含 "X" 的行

---

### Q19: 输出的 Excel 列太多，如何精简？

**A:** 修改模板配置

编辑 `templates/*.json`，删除不需要的列：

```json
{
  "output": {
    "columns": [
      // 只保留需要的列
      {"header": "姓名", "source": "field", "field": "姓名"},
      {"header": "性别", "source": "field", "field": "性别"}
    ]
  }
}
```

## 其他问题

### Q20: 如何处理双面扫描的文档？

**A:** 使用隔页推理

**步骤 1：处理正面**
1. 启用隔页推理
2. 处理图片目录
3. 生成 output.xlsx

**步骤 2：处理反面**
1. 再次启用隔页推理
2. 处理同一目录
3. 数据会追加到 output.xlsx

---

### Q21: 可以同时处理多种文档类型吗？

**A:** 不建议

每种文档类型使用不同的模板：
1. 分别处理不同类型的文档
2. 每次处理前切换模板
3. 或创建通用模板（但准确率会降低）

---

### Q22: 如何备份配置？

**A:** 复制配置文件

```bash
# 备份
cp config.json config.json.backup
cp templates/hukou_register.json templates/hukou_register.json.backup

# 恢复
cp config.json.backup config.json
cp templates/hukou_register.json.backup templates/hukou_register.json
```
