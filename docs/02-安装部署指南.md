# DocExtractor 文档信息提取系统 - 安装部署指南

## 📋 系统要求

### 硬件要求

#### 最低配置
- CPU: 4 核心
- 内存: 8GB
- 硬盘: 20GB 可用空间
- 操作系统: Windows 10/11, Linux, macOS

#### 推荐配置
- CPU: 8 核心以上
- 内存: 16GB 以上
- GPU: NVIDIA GPU（显存 4GB+）
- 硬盘: 50GB 可用空间
- 操作系统: Windows 10/11, Linux

### 软件要求
- Python 3.8 - 3.12
- NVIDIA 驱动（GPU 模式）
- CUDA 11.8 或 12.9（GPU 模式）

---

## 🚀 安装步骤

### 步骤 1：安装 Python 环境

#### Windows 系统
1. 下载 Python 3.11：https://www.python.org/downloads/
2. 安装时勾选 "Add Python to PATH"
3. 验证安装：
```bash
python --version
```

#### Linux 系统
```bash
# Ubuntu/Debian
sudo apt update
sudo apt install python3.11 python3-pip

# CentOS/RHEL
sudo yum install python3.11 python3-pip
```

---

### 步骤 2：创建虚拟环境（推荐）

```bash
# 创建虚拟环境
python -m venv ocr-env

# 激活虚拟环境
# Windows:
ocr-env\Scripts\activate

# Linux/macOS:
source ocr-env/bin/activate
```

---

### 步骤 3：安装 PaddlePaddle

#### GPU 版本（推荐）
```bash
# CUDA 12.9
python -m pip install paddlepaddle-gpu==3.1.1 -i https://www.paddlepaddle.org.cn/packages/stable/cu129/

# CUDA 11.8
python -m pip install paddlepaddle-gpu==3.1.1 -i https://www.paddlepaddle.org.cn/packages/stable/cu118/
```

#### CPU 版本
```bash
python -m pip install paddlepaddle==3.1.1 -i https://www.paddlepaddle.org.cn/packages/stable/cpu/
```

---

### 步骤 4：安装 PaddleOCR

```bash
python -m pip install "paddleocr[all]"
```

---

### 步骤 5：安装其他依赖

```bash
pip install ollama tqdm openpyxl pyyaml pandas
```

---

### 步骤 6：安装 Ollama

#### Windows 系统
1. 下载 Ollama：https://ollama.com/download
2. 运行安装程序
3. 安装完成后，Ollama 会自动启动

#### Linux 系统
```bash
curl -fsSL https://ollama.com/install.sh | sh
```

#### 启动 Ollama 服务
```bash
ollama serve
```

---

### 步骤 7：下载 LLM 模型

```bash
# 推荐模型（32B，高精度）
ollama pull deepseek-r1:32b

# 备选模型（7B，速度快）
ollama pull qwen2.5:7b
```

---

### 步骤 8：部署系统文件

1. 解压发行包到目标目录，例如：
   - Windows: `C:\ocr-llm\`
   - Linux: `/opt/ocr-llm/`

2. 目录结构应该如下：
```
ocr-llm/
├── config.json
├── menu.py
├── main.py
├── templates/
│   └── hukou_register.json
├── models/              # OCR 模型目录
│   ├── PP-DocLayout-L/
│   ├── PP-OCRv5_server_rec/
│   └── ...
└── 项目文档/
```

---

### 步骤 9：配置系统

#### 9.1 修改 config.json

打开 `config.json`，修改以下配置：

```json
{
  "ollama": {
    "host": "http://localhost:11434",     // Ollama 服务地址
    "model": "deepseek-r1:32b"            // 使用的模型
  },
  "device": "gpu:0",                      // gpu:0 或 cpu
  "models": {
    "layout_detection": {
      "name": "PP-DocLayout-L",
      "path": "C:/ocr-llm/models/PP-DocLayout-L"  // 修改为实际路径
    },
    // ... 其他模型路径
  }
}
```

#### 9.2 配置模型路径

**方法 1：使用绝对路径（推荐）**

将所有模型的 `path` 修改为实际的绝对路径：
```json
"path": "C:/ocr-llm/models/PP-OCRv5_server_rec"
```

**方法 2：使用默认路径**

将模型文件放到以下位置：
- Windows: `C:\Users\你的用户名\.paddlex\official_models\`
- Linux: `~/.paddlex/official_models/`

---

### 步骤 10：验证安装

#### 10.1 测试 Ollama 连接
```bash
cd C:\ocr-llm
python test_ollama_connection.py
```

预期输出：

预期输出：

## 🔧 常见安装问题

### 问题 1：pip 安装速度慢
**解决方案：** 使用国内镜像源
```bash
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple <包名>
```

### 问题 2：CUDA 版本不匹配
**解决方案：** 检查 CUDA 版本
```bash
nvidia-smi
```
根据显示的 CUDA 版本选择对应的 PaddlePaddle 版本。

### 问题 3：Ollama 无法启动
**解决方案：**
1. 检查端口 11434 是否被占用
2. 查看 Ollama 日志
3. 重启 Ollama 服务

### 问题 4：模型文件找不到
**解决方案：**
1. 检查 `config.json` 中的路径是否正确
2. 确认模型文件确实存在
3. 使用绝对路径而不是相对路径

## 📦 离线部署

如果目标环境无法联网，需要提前准备：

1. **Python 离线安装包**
   - 下载所有依赖的 wheel 文件
   - 使用 `pip download` 命令

2. **Ollama 离线安装**
   - 下载 Ollama 安装程序
   - 提前下载模型文件

3. **OCR 模型文件**
   - 完整的 models 目录
   - 所有必需的模型文件
