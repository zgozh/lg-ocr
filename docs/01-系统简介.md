# DocExtractor 文档信息提取系统 - 系统简介

## 📌 系统概述

DocExtractor 文档信息提取系统是一款基于 PaddleOCR 和大语言模型的智能文档处理工具，专门用于批量识别和提取结构化文档中的信息，并自动生成 Excel 汇总表。

## ✨ 核心特性

### 1. 高精度 OCR 识别
- 基于 PaddleOCR PP-OCRv5 引擎
- 支持印刷体和手写体识别
- 支持有线表格和无线表格识别
- 自动版面分析和文档矫正

### 2. 智能信息提取
- 使用大语言模型理解文档语义
- 自动提取关键字段信息
- 支持自定义提取规则
- 失败自动重试机制

### 3. 批量处理能力
- 支持目录批量扫描
- 自动生成 Excel 汇总表
- 实时进度显示
- 错误自动兜底

### 4. 灵活配置
- JSON 配置文件，易于修改
- 模板化字段定义
- 支持自定义文档类型
- 可配置 LLM 服务

## 🎯 适用场景

- **档案数字化**：户籍登记表、人事档案、历史档案
- **政务文档处理**：证件识别、表单提取、公文处理
- **企业文档管理**：合同管理、发票识别、单据处理
- **教育文档处理**：试卷识别、成绩单提取、学籍管理

## 📊 处理流程

```
1. 扫描图片文件
   ↓
2. OCR 文字识别
   ↓
3. 版面分析 + 表格识别
   ↓
4. 文本排序（从左到右、从上到下）
   ↓
5. LLM 语义理解 + 字段提取
   ↓
6. 生成 JSON 结果
   ↓
7. 汇总到 Excel 文件
```

## 💻 系统组成

### 核心程序
- `menu.py` - 交互式菜单程序（推荐使用）
- `main.py` - 命令行程序（高级用户）

### 配置文件
- `config.json` - 系统配置（Ollama、模型路径、设备）
- `templates/*.json` - 文档模板（字段定义、提取规则）

### 工具脚本
- `test_ollama_connection.py` - 测试 Ollama 连接

## 📈 性能指标

### GPU 模式（推荐）
- **硬件要求**：NVIDIA GPU（显存 4GB+）
- **处理速度**：3-5 秒/张（RTX 3090）
- **处理能力**：600-1000 张/小时

### CPU 模式
- **硬件要求**：4 核心 CPU，8GB 内存
- **处理速度**：30-60 秒/张
- **处理能力**：60-120 张/小时

## 🔒 数据安全

- 所有处理均在本地完成
- 不上传任何数据到云端
- 支持离线运行（需提前配置）
- 原始图片不会被修改
